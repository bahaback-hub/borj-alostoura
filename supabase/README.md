# إعداد قاعدة البيانات السحابية (Supabase) — دليل مصوّر

هذا الدليل يجعل بيانات المنظومة تُحفَظ في السحابة (لا تضيع عند حذف بيانات المتصفح)
مع تسجيل دخول بالإيميل وكلمة مرور.

> ملاحظة: كل الخطوات **تُنفَّذ من موقع Supabase على المتصفح**، بلا أي برمجة.

---

## الخطوة 1 — إنشاء الجداول (مرة واحدة فقط)

1. افتح لوحة مشروعك: <https://supabase.com/dashboard/project/kxgqwkhqogfzggunxogt>
2. من القائمة اليسرى اختر **SQL Editor**.
3. اضغط **New query**.
4. افتح ملف `supabase/setup.sql` من هذا المستودع، وانسخ **كل محتواه** والصقه في المربع.
5. اضغط الزر الأخضر **Run** (أو Ctrl+Enter).
6. يجب أن ترى رسالة **Success. No rows returned**.

---

## الخطوة 2 — إنشاء المستخدمين (حساب لكل موظف)

1. من القائمة اليسرى اختر **Authentication** → **Users**.
2. اضغط **Add user** → **Create new user**.
3. أدخل:
   - **Email:** بريد داخلي للموظف، مثل `manager@borj.app` (لا يلزم أن يكون بريدًا حقيقيًا).
   - **Password:** كلمة مرور قوية للموظف.
   - ✅ علّم على **Auto Confirm User** (مهم — وإلا لن يستطيع الدخول).
4. اضغط **Create user**.
5. كرّر لكل موظف (المدير، المصممون، مدير المستودع، الفنيون).

> ⚠️ اكتب الإيميلات وكلمات المرور وسلّمها لكل موظف.

---

## الخطوة 3 — ضبط دور كل مستخدم

بعد إنشاء المستخدمين، كل مستخدم يحصل تلقائيًا على دور **مصمم**. لضبط الأدوار:

1. من القائمة اليسرى اختر **Table Editor** → جدول **profiles**.
2. ستجد صفًا لكل مستخدم (بعمود `id` = معرّف المستخدم).
3. اضبط لكل مستخدم:
   - **role:** واحدة من `supervisor` / `designer` / `warehouse` / `technician`.
   - **person:** اسم الموظف (مثل «أبو جمال»).
4. احفظ التعديلات (تحفظ تلقائيًا عند الخروج من الخلية).

**بدائل حسب جدول الأدوار:**
- مدير عام: `role = supervisor`
- مصمم: `role = designer` + `person = أبو جمال`
- مدير المستودع: `role = warehouse`
- فني تركيب: `role = technician` + `person = اسم الفني`

> لتغيير دور مستخدم بسرعة، يمكنك من **SQL Editor** تشغيل:
> ```sql
> update public.profiles set role = 'supervisor', person = 'المدير' where id = '<معرّف المستخدم>';
> ```
> تجد المعرّف في صفحة Authentication → Users.

---

## الخطوة 4 — الدخول إلى المنظومة

1. افتح: <https://bahaback-hub.github.io/borj-alostoura/>
2. ستظهر شاشة **تسجيل الدخول**.
3. أدخل الإيميل وكلمة مرور الموظف.
4. ادخل — وستُحمَّل بياناتك من السحابة، وكل تعديل يُحفظ فورًا.

---

## ملاحظات

- **المفاتيح في الكود:** `SUPABASE_URL` و `SUPABASE_ANON` أعلى `app.js`. المفتاح العام آمن للعرض.
- **لا تضع أبدًا** المفتاح السرّي (`service_role`) في الكود — فهو يملك كل الصلاحيات.
- **رسمات المصنع:** تُرفع تلقائيًا إلى دلو التخزين `drawings` (ينشئه ملف SQL). ملفات PDF/الصور تظهر برابط عام.
- **بوابة الفنيين** (`?tech=1`) تبقى تعمل بلا حساب كما هي.
- **الجلسة:** تبقى فعّالة وتُجدَّد تلقائيًا؛ وقد تحتاج إعادة تسجيل الدخول كل فترة زمنية (عادةً طويلة).
- لتغيير كلمة مرور مستخدم: Authentication → Users → القائمة (⋯) → Reset password.
